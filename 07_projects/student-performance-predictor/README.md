# 🎓 Student Performance Predictor

A beginner-friendly Machine Learning project that predicts a student's marks based on study hours and attendance.

## 📌 Project Overview

This project uses Linear Regression to predict student marks from two features:

- Study Hours
- Attendance Percentage

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Linear Regression

## 🔄 Machine Learning Workflow

1. Prepare the dataset
2. Split data into training and testing sets
3. Train the Linear Regression model
4. Make predictions
5. Evaluate the model using Mean Absolute Error

## 📊 Features

- Predict student marks
- Evaluate model performance
- Test predictions on new student data
